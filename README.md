# 우리집 그린체크

제6회 그린리모델링 챌린지 AI 플랫폼 아이디어 부문을 위한 **모바일 웹 프로토타입**입니다. 상위 폴더의 최종 제안요약서를 바탕으로 만들었습니다.

## 공개 체험 주소

https://greencheck-demo.pages.dev/

Cloudflare Pages 무료 정적 호스팅과 기본 주소를 사용합니다. 배포 후 첫 화면과 대표 사례 불러오기 동작을 확인했습니다.

## 실행

Node.js 22.18 이상을 권장합니다. 의존성은 현재 설치되어 있습니다.

```sh
cd /Users/cho/Developer/GreenRemodel/prototype
npm run dev
```

브라우저에서 `http://localhost:5173/`를 엽니다. 최초 설치나 다른 컴퓨터에서는 `npm run install:ci`를 먼저 실행하세요. Node 22.12 이하에서는 동작하지 않을 수 있습니다.

```sh
npm run typecheck
npm test
npm run build
npm start
```

`npm start`는 빌드 결과를 실행합니다. 개발용 기본 주소와 별개로, 실행 출력에 표시되는 로컬 주소를 이용하세요. 로컬 실행에는 계정·API 키·DB가 필요하지 않습니다.

## 3분 시연

1. **대표 사례 불러오기**를 누릅니다. 집 정보와 답변, 예시 자료가 채워지고 창호 사진 수집 화면이 열립니다.
2. 요청 이유와 촬영 안내를 설명한 뒤 **다음으로**를 눌러 벽면 사진과 고지서로 진행합니다. 전체 상담을 보려면 **처음부터 → 초기화하기** 후 불편을 직접 입력합니다.
3. **사전점검 결과 보기**에서 창호 4단계, 벽체 3단계, 환기 2단계, 냉난방 설비 판단 보류를 확인합니다. 부위를 펼치면 관찰·추정·미확인을 볼 수 있습니다.
4. **개선 효과 비교하기**에서 세 대안을 바꿔봅니다. 동일한 수치로 그래프·비교표·보고서가 갱신됩니다.
5. **이 대안으로 상담 준비**에서 보고서를 검토합니다. 동의를 체크해야 **상담 신청 체험하기**가 활성화됩니다. 실제 전송·예약은 없습니다.
6. **지원사업 준비 살펴보기**에서 가상 지원사업의 조건과 서류 체크리스트를 확인합니다.

상단 단계 또는 하단 화면 선택으로 언제든 이동할 수 있습니다. 결과 화면을 먼저 열면 없는 자료는 판단 보류로 남습니다. **대표 사례 불러오기**는 현재 기록을 덮어쓰므로 확인 창이 표시됩니다.

## 자료와 저장

- 답변, 선택 대안, 진행 단계, 상담 동의·완료 상태, 체크리스트는 이 브라우저의 localStorage에만 저장됩니다.
- **처음부터 → 초기화하기**로 기록을 초기화합니다.
- JPG/PNG/WEBP 이미지를 미리 볼 수 있으며 고지서 단계에서는 PDF도 가능합니다. 파일당 10MB 이하입니다.
- 첨부 파일 원본과 미리보기 URL은 저장·업로드하지 않습니다. 새로고침 시 파일명·유형만 남으며 **재첨부 필요**로 표시됩니다.
- 실제 첨부 이미지에 대한 분석은 하지 않습니다. 예시 사진을 불러와야 해당 가상 사례의 등급이 표시됩니다.
- 입력이나 대안을 변경하면 이전 동의·데모 신청 완료 상태가 초기화됩니다.
- 자유 입력은 기록되지만 질문은 고정 대표 사례를 따릅니다.

## 예시 수치

| 항목 | 현재 | 창호 | 단열 | 창호+단열 |
|---|---:|---:|---:|---:|
| 에너지 kWh/년 | 12,000 | 9,000 | 8,400 | 6,600 |
| 냉난방비 만원/년 | 180 | 135 | 126 | 99 |
| 절감률 | — | 25% | 30% | 45% |
| 공사비 만원 | — | 450–650 | 600–850 | 950–1,350 |

실제 계산 엔진·요금표·견적에서 얻은 값이 아닙니다. 에너지 사용량은 고정 mock 데이터이며 비용은 150원/kWh의 단순 환산입니다. 예시 범위 ±10%는 통계적 신뢰구간이 아닙니다. 지원사업도 실재 공고가 아닌 가상 사례입니다.

## 구성

- `app/page.tsx`: 상담·결과·비교·보고서·지원 준비 화면과 브라우저 상태
- `lib/greencheck.ts`: 시나리오, 모델, 점검 근거, 수치, 저장 검증
- `app/globals.css`: 반응형 디자인과 보고서 인쇄 스타일
- `components/ui`: Sites 기본 UI 컴포넌트
- `tests/greencheck.test.mjs`: 자료 누락·업로드·수치 일관성·복원 검증
- `output/screenshots`: 제안서용 화면 캡처
- `SOURCES.md`: AI 및 오픈소스 활용범위와 출처
- `QA.md`: 검증 기록

실제 서비스로 확장할 때에는 질문 결정·평가·시뮬레이션·지원사업 조회를 별도 서비스로 교체하고, 서버 저장·인증·파일 업로드·전송 동의 관리를 구현해야 합니다. 프로토타입의 예시 등급은 전문가가 검증한 기준이 아닙니다.

브라우저가 WebMCP를 지원하면 상태 읽기와 화면 이동 도구를 제공합니다. 지원하지 않는 브라우저에서도 모든 화면은 정상 동작합니다.

## 무료 정적 배포

`next.config.ts`에 `output: "export"`를 설정했습니다. `npm run build`가 `dist/client`에 HTML·JS·CSS·이미지만 출력하며, 서버 없이 실행 가능합니다.

- 배포 대상: Cloudflare Pages Free / 기본 `pages.dev` 주소
- 직접 업로드 파일: `output/greencheck-pages.zip` (2026-09-19 빌드)
- 업로드 내용: `dist/client`의 공개 정적 파일만. 원본 제안서·코드·환경변수·서버 출력물은 제외합니다.
- Cloudflare 계정 로그인 후 Workers & Pages의 Pages 직접 업로드로 zip을 배포합니다. 도메인 구매나 유료 상품 신청은 필요하지 않습니다.
- 현재 상태: 2026-09-19 Cloudflare Pages 배포 완료. 공개 주소 https://greencheck-demo.pages.dev/ 에서 로그인 없이 체험할 수 있습니다.

수정 후 다시 배포할 때는 새로 빌드하고 `dist/client`로 zip을 갱신해야 합니다. 기존 zip은 자동 갱신되지 않습니다.
